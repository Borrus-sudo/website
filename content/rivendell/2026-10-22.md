- Prepping for Cybersec script: 
	- Media Based Vulnerabilities exploit the use of removable media and malicious files to attack systems of users. People remain in the false sense of security that installing a firewall or air-gapping a system is enough to protect it from external threats. Media based vulnerabilities exploit this very negligence by trying to attack the systems from within via infected USBs. CDs, hard disks, SSDs etc. It also includes the use of digital audio/video files which exploit software vulnerabilities in audio/video decoders to harm the system.
	- Attacks:
		- USB hijacking: Malicious USB 
			- Infected USB: Malicious files are present. The victim opens or executes the malicious file.
			- BadUSB: firmware reprogramming. 
		- Social Engineering:
			- USBs in parking lots and try to weaponize curiosity. 
			- Fake QR codes
			- DeepFakes and Synthetic Voices. 
		- Malicious files:
			- Audio and Video files that are affected exploit software vulnerabilities
				- Pirated game or music affects here.
			- Trojanware might introduce it.
			- Malicious PDFs
		- Data theft: 
			- Might copy private files to removable media
		- Malware propogation:
			- Infected devices might infect attached medias to it which can cause it to spread across networks.

		- Block un-authorized USB devices.
		- Scan media before use.
