
Languages communication is majorly done via an auditory medium. Although communication can also be done visually like the sign language. Using an interface is similar to chatting with a person. When we talk with another person, we use language and the auditory medium to transmit our ideas. Whilst using an interface, where the communication is done majorly via using the mouse pointer to click a button, push a slider or typing a textbox, we are also using this actions to communicate using a language. This way of doing things was championed by Alan Kay. To make the Xerox PARC easier to use, they had the used the file and desktop metaphor to craft a visual medium where the user could use the mouse pointer and the keyboard to communicate with the computer their "task". Before this, computers were mainly "text" based in nature which required users to learn lots of shell commands to communicate with the computer. Hence interface design is effectively creating a language and making an interface which allows the user to communicate easily . Alan Kay summarized this technique as [Doing with Image Makes Symbols](https://numinous.productions/ttft/assets/Kay1989.pdf). 

However the grammar of the languages that most of the today's interfaces speak are pretty stunted due the lack of expressivity. The communication between the user and the interface can be compared to that of a pidgin. This is sort of a conversation is pretty suffice for roughly 90% of the software, which Bret Victor classifies as "[[Information Design by Bret Victor#^77a405|Information Software]]". Though,  the grammar is not enough for "[[Information Design by Bret Victor#^39a0fe|Manipulation Software]]". One of the main reasons that the grammar of our interfaces are so stunted is because we [Design with features and not materials](https://thesephist.com/posts/materials/)

So the question arises, how can we create more expressive grammars and intuitive user interfaces that would allow a user to easily learn the grammar and use it effectively to get shit done. What new primitives, techniques and principles we need that can be used to create effective grammars and user-interfaces that would allow for rich and fluid communication between the user and the interface whilst have an easy learning curve.

We draw upon the [[Lego Model]] of grammars as a base to create expressive grammars. To put simply, we think of powerful new primitives, ways to compose them and create new "abstract" primitives on top of the composition. This grammar is reified into the modern interface which is visual, [spatial](https://darkblueheaven.com/spatialsoftware/), [auditory](https://interconnected.org/home/2026/02/27/asymmetry?utm_source=Robin_Sloan_sent_me) and [symbolic](https://maggieappleton.com/programming-portals)[^1] in nature which also allows us to use the full power of our mental faculties. The [[Lego Model]]  is also similar to thesephist's [Design With Materials not Features](https://thesephist.com/posts/materials/) The power of computer medium is that it allows our language to be multi-dimensional in terms of mental faculties. Our underlying language grammar can be expressed and communicated in this new "multi-dimensional" medium to allow for un-precedented man and machine collaboration. Modern AI agents can help bridge the gap of learning the underlying grammar by allowing humans to ask question in English, but most not be seen as a complete replacement.

There is also massive thinking that we need to do in each of these areas to understand which bits of our grammar can be more easily expressed in them. E.g visual is probably more suitable for studying the diagrams, visualizing an simulation. Symbolic notations are better for precise tasks.

Matt Webb wrote about the desirable properties a "good" notation should possess: 
- Composable
- Shareable
- Degradable
- Learnable
- Semantic
- Grammatical
- Efficiently expressive
- Suggestive
- Intentional
- Legible
