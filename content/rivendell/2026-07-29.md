HTML Web components are basically the solution to my [[mycelium - wood wide web]] woes of having interactivity, rendered html but not duplicating the content in js. 
The standard web component is more like "SPA". 
The HTML web component is thought of as expanding the span of html elements by expanding the basis set. We can then add interactivity to them as JS is loaded. This is progressive enhancement. The HTML web component is on the "light" side of the DOM. 
It does not use shadow DOM, templates or slots. The goal with HTML web components is to take HTML to its maximum possible limits and then use them to expand it. It is HTML with "superpowers"!

It also has been pointed that out that why "web component" and "web component APIs" are slightly different. HTML web components simply use the custom-element web component API majorly to provide for progressive enhancement cause it makes it portable, follows the single responsibility principle and is overall less fragile. Astro uses it to implement its island functionality!
